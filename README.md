### 我关注的 Agent 工程能力

- **需求与任务拆解**：明确输入输出、交付范围、验收标准、依赖和需要人工决策的环节。
- **多 Agent 协作**：按模块和职责分工，隔离文件修改，汇总结果并核验，避免共享工作区冲突。
- **上下文与技能管理**：维护项目指引、技能、历史决策与可复用工作流；区分历史记录和当前事实。
- **代码与验证**：使用仓库证据、接口、定向测试和浏览器验证检查结果；不把生成代码等同于完成交付。
- **工具与业务集成**：结合 API、任务队列、数据库、浏览器工作流和本地服务，把模型能力接入产品。
- **成本与执行边界**：明确费用、权限、隐私和平台规则；高影响操作保留必要的人工确认。
